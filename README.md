# DSiRPC's renders

The launcher's screens, drawn by its own code (`tools/render_launcher.py`),
its demo, its menu music as MP3s (`bright.mp3`, `subtle.mp3`: a loop
of each song), and the desktop app's overlay window in its demo's scenes
(`overlay-*.svg`, `overlay-tetris.gif` and `overlay-mkds.gif`, `tools/render_overlay.py`), for MKDS_TEMP at 4e7b3ff. The README shows the pictures;
`.github/workflows/renders.yml` replaces all of them when a release is
published, so don't edit them here.
